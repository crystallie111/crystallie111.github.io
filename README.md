# YRO portfolio

Frontend-only; suitable for GitHub Pages. No build, backend, API key or external JavaScript dependency. Optional Google Fonts fall back to system fonts.

## Preview and deploy

Open `index.html`, or serve this directory using a static HTTP server. Upload this directory's contents (including `evidence/`) to the root of your GitHub Pages repository. The original source portfolio and Desktop documents are unchanged. Nothing has been published externally.

## Cinematic experience

`experience.html` opens with only the centered name and an Enter button. Enter fades the name away and runs a 2.6-second eased camera flight through the chrome star, with violet bloom, before revealing the tab menu with no section selected. Reduced-motion preferences skip the flight. The menu initially sits in the center. Clicking About, Capabilities, Projects or Contact slides the menu to the side and reveals the selected material in the central reading area. On narrow screens the menu moves to the bottom to preserve reading space. Close, Escape or clicking the selected tab returns to the menu-only view. Arrow keys, Home and End navigate sections after entry. The document stays in one viewport; longer content scrolls inside its panel.

Native WebGL runs locally. Pause motion and reduced-motion settings disable panel animation and freeze the scene. A static SVG keeps the page usable if graphics fail. Animation suspends in hidden tabs; rendering resolution and particle counts are capped.
