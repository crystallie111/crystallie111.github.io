CASE STUDY [04] // DETECTION ENGINEERING

Detection Lifecycle
& Analyst Training

I own the detection rule lifecycle: defining how a rule will be validated, writing its logic, testing it, and maintaining and tuning it. For selected validations, I also conduct red-team simulations to exercise the behavior the rule is intended to detect.

OwnershipEnd-to-end rule lifecycle
PlatformElastic
Team contributionNew-analyst training
Developing areaKubernetes security

CONTRIBUTION

What I owned

I connect rule authoring with validation: plan the test approach, write the detection, run tests, review what the rule detects, and use the findings to refine it. I also help analysts understand the resulting detection content.

Technical scope

ES|QLEQLKQLSigmaMITRE ATT&CKRule validationRed-team simulationRule tuningAnalyst training
01

Rule creation

Built detection content using ES|QL, EQL, and KQL, including behavior-based and indicator-based use cases and Sigma translation work. The detection objective determines which logic and data are appropriate.

02

Validation & testing

I plan how to validate the detection and test the rule against the intended behavior. When appropriate, I perform red-team simulations as part of that validation and use the results to refine the rule.

03

Maintenance & tuning

Maintained and tuned multiple rules as part of ongoing SOC work. This is a continuing responsibility: review rule behavior, understand benign matches, and consider the coverage implications of changes.

04

Training & developing scope

Trained new employees and developed material explaining detection logic, query languages, and tuning. I have also worked on Kubernetes security and rules, an area where my experience is still developing.

DELIVERABLES

What the work produced

  • Detection logic and rule-specific validation approaches
  • Rule testing, including red-team simulations for selected validations
  • Ongoing maintenance and tuning
  • Analyst training and supporting material
  • Contributions to Kubernetes security rules
